## Ejercicio 10 - Competencia de cocina

### Descripción
Simulación de una competencia de cocina con 5 participantes y 5 rondas.
Muestra la tabla de posiciones después de cada ronda y una tabla final con el ranking definitivo.

### Dependencias
- Python 3.x
- Jupyter Notebook

### Instalación
pip install jupyter

### Cómo ejecutar
1. Abrir una terminal en la carpeta raíz del proyecto
2. Ejecutar: jupyter notebook
3. Ir a la carpeta notebooks/
4. Abrir ejercicio_10.ipynb
5. Ejecutar las celdas.
